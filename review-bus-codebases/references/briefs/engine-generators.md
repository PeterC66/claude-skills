Review for: style consistency (naming, module pattern, exports, error handling, argument parsing), standards (CommonJS vs ESM, `use strict`, magic numbers, dead code, duplicated helpers across generators, giant functions, top-to-bottom scripts vs importable modules), structure (what the generators share and re-implement; what has been extracted since the last run and whether the extraction's caller is its only caller), maintainability (testability — which generators are covered only by the byte gate; unclear ownership of config keys; comments that describe history rather than behaviour).

Method: do not read every line. Sample deliberately: read the head and a representative 200-line window of each large file, grep for patterns (`function ` counts per file, `process.argv`, `require(` fan-in, `TODO|FIXME|XXX|HACK`, `console.log`, `catch\s*\(\w*\)\s*\{\s*\}`, repeated helper names such as `esc`, `wrap`, `round`, `clamp` defined in more than one file). Measure the duplication concretely, with `comm` over whitespace-stripped lines where two files look alike.
